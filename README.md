# Herons U6 — Launch Landing Page

Static landing page for the Herons Motorcycles U6 sports motorcycle launch.

## Deploy to GitHub + Vercel

1. Create a new GitHub repository.
2. Upload **everything inside this folder** (not just the ZIP file):
   - `index.html`
   - `favicon.svg`
   - `README.md`
   - `assets/u6-hero.jpg`
   - `assets/u6-engine.jpg`
   - `assets/u6-india.jpg`
3. In Vercel, import the GitHub repository.
4. Framework preset: **Other** (or leave Vercel to detect it as a static site).
5. Build command: **leave blank**.
6. Output directory: **leave blank / root**.
7. Deploy.

No Node.js, npm, build step, database, or environment variables are required for the current static version.

## Important before launch

The **Book Now** button is currently a front-end demo interaction. Replace the `href="#"` on `#bookBtn` in `index.html` with your real booking form/URL when ready.

The countdown is set to **8 November 2026**, the Diwali date used for the launch campaign.

# Herons U6 — Launch Landing Page

Static, Vercel-ready landing page for the Herons Motorcycles U6.

## Deploy
Upload the contents of this folder to the root of a GitHub repository and import that repository into Vercel.

- Framework: Other / static
- Build command: none
- Output directory: leave default / root

## Important
The motorcycle images are embedded directly inside `index.html` as base64 data. This makes the site self-contained and prevents broken-image errors caused by missing `/assets` paths.
